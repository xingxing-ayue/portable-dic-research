便携式 DIC 系统选型方案

本表对照工业数字图像相关（DIC）采集平台的三条路线：Mini PC（x86 小主机）、树莓派（Pi 5 / CM5）、FPGA（AMD Kria K26）。金额为人民币，美元按 1 美元 ≈ ¥6.67 折算。本期选型决策以 2D 为准，3D 暂不考虑：方案对照表与主表只讲 2D，3D 见单独一页“3D 方案”。

一页核心

总推荐：首选 Mini PC（N305 档起，2D ¥31,956，商用软件直接跑）；树莓派只在接受开源链自验证时选；FPGA只在需要硬件确定性同步 / 预处理时选。应用场景：DIC 采集计算客户现场；软件用户自备，不含在整套价内。

三个 2D 价（整套，软件自备）

  • Mini PC ¥31,956 起
  • 树莓派 ¥25,971
  • FPGA ¥27,600

三个关键参数

  • 散斑：尺寸 3–5 px、密度约 50%、对比度 ≥50%（iDICs 良好实践指南口径）
  • 标定板：点位精度 ±0.002 mm
  • 同步：硬件触发最确定；GigE PTP 1–2 µs 为接口规范口径，非实测

三个风险

  • 性能无实测：三行均无目标机型 DIC 全流程实测，精度数字为厂商指标
  • 进口断供：KV260 官网交期 26 周；Kowa 镜头缺货到 2026-12-01
  • 到手价未定：整套价未计关税 / 运费 / 税，未核实

三个下一步

  • 按“专家验收七条”做原型验证
  • 确认采购清单与到手价（关税 / 运费 / 税逐项核）
  • 现场部署前完成标定 + 已知场验证

怎么选

问题一

要不要商用软件？

要。要用 VIC-2D、ZEISS CORRELATE，要厂商支持与可对照验证——商用软件全是 x86 Windows，只有这一行能装。

→ Mini PC

不要。开源链（pyALDIC 等）可接受，精度自己验证。

→ 树莓派 → FPGA
问题二

要不要实时相关？

要实时全场应变。2D 在线全场速率目前没有公开数据，写未核实；商用软件是三行中唯一提供在线相关的路线，但其 2D 全场在线速率同样无公开指标，不能拿 3D 指标推断 2D。

→ Mini PC

只要采集实时、相关可离线。低成本采集选树莓派；要确定性采集与硬实时预处理选 FPGA。

→ 树莓派 → FPGA

不需要，纯离线算。帧率需求低时没必要为实时付钱。

→ 树莓派
问题三

预算多少？

压到最低：三行中最便宜的一行，整套价见方案对照表。

→ 树莓派

预算居中，且团队有 FPGA 开发能力，能承担自研相关算法的周期。

→ FPGA

预算最高一档，要开箱接相机就能采集处理、能交付。

→ Mini PC

Mini PC

三行中唯一能直装商用 DIC 软件的便携路线——x86 + Windows，现场采集与处理一体化

2D ¥31,956 起

软件自备，不含在整套价内；整套价只含硬件 + 耗材。

相关速度（统一工况）：本机实测未核实。已核实参照：VIC-Gauge 250Hz 与 280Hz（同出 2026 规格；虚拟应变计读数，非全场）；同行评审多线程 DIC 14.5 万点/秒@48 核——本机最高 14 核，不能直接套用；GPU 实时 2D-DIC 1.2kHz 是独显实现，本机只有核显，未核实。2D 在线全场速率无公开数据，未核实。

测量精度：应变分辨率 10 µε；应变范围 0.005%–2000%，厂商页另写 50 µε to 2500%+（VIC 厂商指标）；位移亚像素精度 VIC-3D ±0.005 px（2024 年综述口径，非横向实测；同表 XTDIC / PMLAB / LaVision 为 ±0.01 px）。

散斑与标定：标定板 100×100mm 点阵。

同步精度：2D 单相机硬件触发，并与试验机或 DAQ 对齐；USB3 相机靠硬件触发线。

视场与工作距离：与另两行共用同一成像链（5MP 相机 + 12.5mm 镜头），视场随工作距离变化，三行无差异；具体视场数值未核实。

在线 / 离线：在线 + 离线。商用软件提供在线相关，但 2D 在线全场速率无公开数据，未核实；离线精算可做，采集与处理同一台机器完成。

  • 基线四项 ¥30,762：相机 ¥7,704、镜头 ¥1,934、光源 ¥5,336、标定板 ¥15,788

  • 无 PCIe 插槽、无独显：CXP / Camera Link 采集卡不能直装，只能走雷电扩展坞，兼容性未核实
  • 高速大面阵 24MP 100fps 超出全部 USB 方案
  • 整机功耗 28–79W 量级，需外接电源与显示器，是可搬运、不是手持
  • 已有商用软件授权、或准备采购，要把 DIC 搬进现场的团队
  • 2D 准静态 / 低速动态现场采集加处理一体化
树莓派

最低成本的 2D 入门与多机位采集——开源链、离线处理

2D ¥25,971

软件走开源链（pyALDIC 等）¥0；软件自备，不含在整套价内，整套价只含硬件 + 耗材。

相关速度（统一工况）：未核实。Pi 5 全场相关无公开实测；2019 年旧机型论文约 2 帧/秒仅作下限参考，不推算 Pi 5。统一工况下只能离线算。

测量精度：未核实。应变分辨率、应变范围、位移亚像素精度均无公开实测，且无商业软件可对照验证。

散斑与标定：采集端可做散斑质量检查。

同步精度：未验证。2D 单相机硬件触发，并与试验机或 DAQ 对齐；GigE PTP 的 µs 级是接口规范值，Pi 上实测未验证。

视场与工作距离：工业相机路线与另两行共用同一成像链；另可接树莓派 CSI 相机（HQ 12.3MP 卷帘快门 / GS 1.58MP 全局快门）。具体视场数值未核实。

在线 / 离线：离线为主。在线只能采集、预览与散斑质量检查；75fps 视频只能离线相关，实时全场做不到。
  • Pi 5 8GB ¥1,167、官方 27W 电源 ¥86、microSD 32GB ¥133、M.2 HAT+ ¥80、官方 SSD 512GB ¥300
  • 相机 ¥7,704、镜头 ¥1,934、环形光 ¥2,261、标定板 ¥12,306
  • 不含显示器、线缆、散热、结构件
  • 商用软件与 MATLAB / Ncorr 跑不了；无现成整机，须自研载板、散热、触发与报告链，逐步实装验证
  • 不能实时全场、不能高速、不能做认证 / 计量场景
  • 预算有限、帧率需求低、离线分析可接受的 2D 入门
  • 教学与学生实验、现场初筛
  • 多机位低成本并行采集（已有 4 台树莓派做 DIC 采集的公开发表案例）
FPGA · Kria K26

确定性采集与硬实时预处理前端——强在采集侧，不是相关计算平台

2D ¥27,600 起

软件自备，不含在整套价内；整套价只含硬件 + 耗材。

相关速度（统一工况）：未核实。全场相关（子区 NCC / ZNCC + 亚像素迭代）没有现成 FPGA 实现，须自研 RTL / HLS，速度无公开数据；已核实的只有线速率预处理与四路相机流并行、亚 20ms 延迟的部署案例。

测量精度：未核实。相关算法须自研，应变分辨率、应变范围、位移亚像素精度均无公开数据。

散斑与标定：可在线评估散斑尺寸、覆盖率与对比度。

同步精度：2D 单相机硬件触发，并与试验机或 DAQ 对齐；触发由可编程逻辑直接驱动，采集、预处理、落盘时延固定；GigE 相机 PTP 对齐到 µs 级（应用笔记实测 2 µs，为接口规范口径）。

视场与工作距离：与另两行共用同一成像链；另有 MIPI / SLVS-EC 直采路线（KR260 接 IMX547 5MP，与基线相机同款传感器）。具体视场数值未核实。

在线 / 离线：在线预处理、离线相关。去噪、去畸变、ROI 裁切、散斑评估以线速率硬实时跑；相关计算离线或回传工作站。
  • KV260 套件 ¥1,661（KR260 方案 2D ¥28,267）
  • 相机 ¥7,704、镜头 ¥1,934、光源 ¥2,261、标定板 ¥12,306、USB3 锁紧线 ¥267、三脚架 ¥1,467
  • 另不含 NVMe、喷斑耗材、定制载板、关税运费；KV260 电源另购约 ¥167
  • 注意：KV260 官网交期 26 周，供货是采购风险
  • 开发门槛三行最高：工具链 Vivado + Vitis，相关核、标定、同步、报告链全须自研
  • 商用 DIC 软件跑不了；DPU 1.2 TOPS（KV260 实装）约是 Jetson Orin Nano Super 的 1/50，AI 算力弱
  • CXP / Camera Link 接不进（套件无 PCIe 插槽）；没有量产实证，只有原型级案例
  • 对采集确定性、硬件触发同步有硬要求，且有 FPGA 开发能力的团队
  • 低功耗多路并行采集（整机低于 10W 量级）
  • 作硬实时预处理前端，精算回传工作站 / 服务器

市场验收

目标用户：DIC 采集计算客户现场。

  • 标定验收未验证标定板点位精度 ±0.002 mm（已有依据），精度证书随附；标定程序与重投影误差阈值未定 / 待实测。
  • 已知场验证未验证用已知位移 / 已知应变场实测，结果与厂商指标对照；通过阈值未定 / 待实测。
  • 与参考系统比对未验证同一试件与应变片或商用 DIC 系统比对；比对偏差阈值未定 / 待实测。

专家验收七条

  • 1. 散斑已满足散斑尺寸 3–5 px、密度约 50%、对比度 ≥50%，依据 iDICs 良好实践指南。
  • 2. 标定已满足标定板点位精度 ±0.002 mm；未验证标定重投影误差、标定程序。
  • 3. 同步未验证2D 单相机触发对齐有说法、无实测；双目同步抖动未核实。
  • 4. 精度验证未验证已知位移 / 已知应变场验证试验没有做，现有效度数字全是厂商指标。
  • 5. 不确定度评估未验证没有做不确定度评估。
  • 6. 软件验证已满足商用软件有厂商验证；未验证开源链在 Pi 上实装未验证。
  • 7. 溯源未验证标定板精度证书随附与否未核实。
